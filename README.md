🚀 Neural Network From Scratch — Machine Learning Project (NumPy + MNIST)

Today I worked on building a 2-layer Neural Network from scratch using NumPy and the MNIST handwritten digits dataset. This project helped me understand the internal mechanics of neural networks beyond high-level libraries.

🔍 Project Overview
The goal was to manually implement every core component of a neural network, including:
• Data preprocessing & reshaping
• Weight initialization
• ReLU & Softmax activation functions
• Forward and backward propagation
• Gradient Descent optimization
• Accuracy evaluation and predictions

🧠 Tech Stack Used
🐍 Python
📦 NumPy
📊 MNIST Dataset (Keras)
📉 Matplotlib for visualization

🔧 Key Features
✨ Neural Network implemented fully from scratch
✨ Built using only NumPy (no ML frameworks)
✨ Manual forward & backward propagation
✨ Softmax classifier for digit recognition
✨ Visual test prediction output using Matplotlib

📊 How the Model Works
1️⃣ The network reshapes and normalizes handwritten digit images
2️⃣ Performs ReLU activation on hidden layer
3️⃣ Calculates class probabilities using Softmax
4️⃣ Trains using Gradient Descent with parameter updates
5️⃣ Predicts digits and visualizes test results
